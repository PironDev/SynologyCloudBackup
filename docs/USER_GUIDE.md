# Руководство пользователя

## Обзор

CloudBackup копирует данные NAS в облачные аккаунты. Задание может создавать зеркало или архив.

Раздел **Обзор** показывает состояние облачных аккаунтов, занятое место и историю выгрузок. Доступность сведений о квоте зависит от провайдера.

## Аккаунты

Откройте **Аккаунты**, чтобы добавить, проверить или удалить облачный аккаунт. Для удаления аккаунта CloudBackup удаляет сохранённые настройки доступа. Файлы в облаке остаются.

## Задания

Создайте задание во вкладке **Задания**. Выберите исходные папки, аккаунт, целевую папку и режим копирования. Затем задайте расписание или запустите задание вручную.

### Режим «Зеркало»

Режим «Зеркало» отправляет новые и изменённые файлы. Приложение сравнивает размер и время изменения. Если облако сообщает MD5, приложение также сверяет хеш.

В режиме «Зеркало» приложение не удаляет файлы из облака только потому, что их удалили на NAS. Проверьте настройки задания перед запуском.

### Режим «Архив»

Режим «Архив» создаёт архив за один запуск. Архив может включать gzip-сжатие и деление на части.

Задайте число последних архивов для хранения. CloudBackup удаляет только архивы, созданные этим заданием.

Для восстановления одной части используйте `tar -xzf имя.tar.gz`. Для восстановления разделённого архива сначала соедините части в порядке номеров, затем распакуйте архив.

### Расписание и журнал

Выберите расписание из списка или укажите выражение cron из пяти полей. Чтобы запустить задание сразу, нажмите кнопку запуска.

Откройте запуск, чтобы просмотреть журнал. Журнал показывает файлы, ошибки и результат проверки данных.

## Файловый менеджер

Файловый менеджер показывает две панели. Выберите NAS или облачный аккаунт в каждой панели.

Операции в панели NAS выполняются через File Station API в сессии текущего пользователя DSM. DSM проверяет права этого пользователя.

Копирование и перемещение между панелями выполняет фоновая служба пакета. Для каждой локальной папки службе нужны отдельные права. См. [разрешения на папки](INSTALLATION.md#разрешения-на-папки-nas).

Вы можете создавать папки, переименовывать и удалять элементы, загружать файлы с компьютера и скачивать файлы на компьютер. DSM применяет настройки корзины к удалённым файлам. Для копирования или перемещения между панелями используйте кнопки или клавиши F5 и F6.

Клавиша F2 переименовывает элемент. Клавиша F7 создаёт папку. Клавиша Delete удаляет выбранный элемент. Клавиша Tab переключает панель. Backspace открывает родительскую папку.

## Synology File Station

CloudBackup предоставляет локальный WebDAV-шлюз для подключённых аккаунтов. Откройте вкладку **File Station** в приложении, чтобы посмотреть адрес шлюза и пароль.

В DSM откройте File Station и выберите **Инструменты → Подключение к удалённой папке/серверу → WebDAV**. Укажите адрес, порт, путь аккаунта и пароль из CloudBackup.

Удалённые WebDAV-папки могут иметь ограничения на предпросмотр, сжатие и распаковку. Эти функции зависят от File Station.

## Проверка данных

Настройка проверки после загрузки предлагает варианты:

- **Только размер** сравнивает размер файла.
- **Размер и MD5** сверяет размер и MD5, если облако сообщает этот хеш.
- **Полная** скачивает файл обратно, если облако не сообщает хеш, и сравнивает данные.

Полная проверка использует дополнительный сетевой трафик. Выберите её, если нужна повторная проверка данных после загрузки.

## Шифрование и большие файлы

При включённом шифровании CloudBackup шифрует данные на NAS перед отправкой. Сохраните пароль шифрования в безопасном месте. CloudBackup не может восстановить забытый пароль.

Большие файлы можно делить на части. Настройте предельный размер части с учётом ограничений облачного сервиса.

Публичные ссылки недоступны для файлов с включённым шифрованием или разделением на части.

## Если возникла ошибка

1. Проверьте, что пакет запущен в Центре пакетов.
2. Проверьте журнал задания в CloudBackup.
3. Для ошибок доступа проверьте права пользователя DSM и системного пользователя пакета.
4. Для ошибок облака проверьте токен или пароль внешнего приложения.
5. Если проблема повторяется, [создайте отчёт об ошибке](https://github.com/PironDev/SynologyCloudBackup/issues/new?template=bug_report.yml).

Не добавляйте в публичный отчёт пароли, токены, IP-адреса или приватные пути.
