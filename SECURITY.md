# Сообщить об уязвимости

Не сообщайте об уязвимости в публичном issue.

Используйте **Security → Advisories → Report a vulnerability** в GitHub. Этот способ отправляет отчёт сопровождающему приватно.

В отчёте укажите:

- затронутую версию;
- шаги для воспроизведения;
- ожидаемое влияние;
- возможное исправление, если оно известно.

Не прикладывайте реальные пароли, токены, пользовательские файлы или полный журнал NAS. Замените такие значения безопасными примерами.

Сопровождающий рассмотрит отчёт, подтвердит получение и согласует дальнейшие действия. Фиксированный срок ответа не гарантируется.
