# Правила поведения

Участники проекта должны вести себя уважительно и добросовестно.

## Ожидаемое поведение

- Используйте нейтральный и уважительный язык.
- Обсуждайте идеи и код по существу.
- Принимайте корректные замечания.
- Защищайте приватность пользователей.

## Недопустимое поведение

- Оскорбления, угрозы и преследование.
- Дискриминация по личным признакам.
- Публикация чужих персональных данных или секретов.
- Нежелательные личные сообщения после просьбы остановиться.

## Сообщение о проблеме

Обратитесь к сопровождающему через приватный канал GitHub. Не публикуйте приватные сведения в issue.

Сопровождающий может скрыть материал, закрыть обсуждение или ограничить участие нарушителя.
